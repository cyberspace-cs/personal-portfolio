## 一、匹配方法论
- **主轴 = AI Agent 应用开发**：把平台所有面向审计人员与运维人员的"对话/工单/审批/巡检/问答"能力，统一抽象为 Agent 能力，直接命中四厂+腾讯/阿里该类岗位高频要求。
- **辅助 = LLM 推理开发**：平台私有化部署 Hunyuan/Qwen、RAG 服务化、ASR 语音入口，命中推理层岗位。
- **补强 = LLM 算法优化**：以"审计术语 SFT + 事实核查/评测对齐 + 数据飞轮"补齐第三类岗位证据链（Step 4/5 设计中正式纳入）。
- 模块来源：用户已给定的"十类审计支持 + 三大运维 + 五大痛点 + 你的五点解决思路"。
