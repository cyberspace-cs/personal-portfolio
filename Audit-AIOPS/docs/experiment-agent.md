# 科研实验记录智能体（SciLog）· AdventureX 黑客松原型

> 面向 AdventureX 黑客松「科研 / 实验记录 Agent」现场主题的参赛 demo 原型。
> **核心理念**：复用 Audit-AIOPS 已验证的混合检索 / 图 RAG / 多模态编码能力，迁移到科研实验记录场景。
> **用户最关心的两点**：① 真实用户数据接入；② 平台起到的效果（可量化）。

---

## 一、它解决什么（现场叙事）

研究者（研究生 / 科研助理）手里有大量**散落、非结构化**的实验记录：markdown 实验笔记、CSV 原始数据、仪器截图、JSON 元数据。它们彼此孤立、难以检索、容易重复做实验。

SciLog 把"你的真实文件"秒级变成**可查询、可追溯、互相关联**的私有知识库：

1. **上传**你真实的实验记录（拖拽 / 多选 / 截图）→ 平台解析、抽取科研实体、入库；
2. **问**"哪种催化剂在 25°C 下产氢速率最高？"→ 基于**你自己的数据**给出带引用、可回溯的回答，不幻觉；
3. **看见**跨实验知识图谱：哪些材料 / 方法把不同实验连了起来；
4. **被提醒**：有高度相似的实验（疑似重复），避免重复劳动与试剂浪费；
5. **量化效果**：接入记录数、抽取实体数、跨实验关联数、潜在重复数、估算节省时间——随你的数据真实变化。

## 二、真实用户数据接入（最最关键）

端点：`POST /api/experiments/upload`（multipart 文件上传）。

支持与处理：

| 类型 | 扩展名 | 处理 |
|---|---|---|
| 实验笔记 | `.md` `.txt` | 解析标题（# 标题 / 文件名）、抽取「键：值」字段作为补充实体，正文入库 |
| 表格数据 | `.csv` | 解析表头为实体，汇总行数与首行样本，转为可检索文本 |
| 结构化 | `.json` `.jsonl` | 解析 dict / list 字段名为实体，值写入正文 |
| 截图 | `.png` `.jpg` `.jpeg` `.webp` `.gif` | 落盘后调用可插拔视觉编码器（`proxy` 默认 / 真实 VLM 可插拔）转文本再入库 |

- 所有记录落盘到 `data/experiments/records.jsonl`（索引）+ `data/experiments/uploads/`（原始文件），**进程重启不丢**。
- 实体抽取用「科研领域词典 + 化学式正则 + 数值参数归一」替代 LLM（纯 CPU、零依赖、可复现），与既有图 RAG「领域词典替代 LLM 抽取」一脉相承；覆盖光催化示例领域，并通过化学式 / 参数正则补抽，跨领域也能连出关系。
- **平台不替用户编造数据**：所有问答都基于用户自己上传的内容，未命中如实告知。

## 三、平台起到的效果（量化）

端点：`GET /api/experiments/metrics`，全部从真实入库数据实时计算：

| 指标 | 含义 | 算法 |
|---|---|---|
| `records` | 已接入记录数 | 直接计数 |
| `entities` | 抽取科研实体数（材料/方法/参数/指标） | 去重并集 |
| `cross_links` | 跨实验关联数 | 共同出现在 ≥2 条记录的实体对数（把不同实验"连"起来） |
| `potential_duplicates` | 潜在重复实验数 | 实体 Jaccard 相似度 ≥0.5 的记录对，典型如「基准 vs 重复性验证」 |
| `estimated_time_saved_hours` | 估算节省时间 | 每条记录手工整理+检索约 15 分钟 → 平台秒级完成（演示假设口径，随数据量线性增长） |

示例（8 条光催化示例实验，已 seed）：records=8、entities=57、cross_links=167、potential_duplicates=3（头条命中 E1 基准 ↔ E7 重复性验证，Jaccard 0.565）、估算节省 2.0h。

> 这些指标**随你上传的数据量真实变化**，是平台价值最直接的证据——黑客松现场可当场演示："你传得越多，图谱越密、关联越多、节省越多"。

## 四、接地问答（基于你的数据，可追溯）

端点：`POST /api/experiments/query`（`{question, top_k}`）。

- 复用混合检索（`KeywordRetriever` TF-IDF + `VectorRetriever` FAISS + RRF 融合）对用户**自己的实验**做检索；
- 返回 `answer`（引用命中最相关记录 + 关键要素 + 来源文件）、`sources`、`retrieved`（含实体与类型）；
- 回答明确标注「基于您上传的 N 条真实实验记录」「点击来源可回溯到原始文件」，确保结论可追溯、可核查、不幻觉。

---

## 五、跨实验知识图谱

端点：`GET /api/experiments/graph`。

- 返回科研实体共现图：节点 = 实体（`records` 字段=出现记录数，决定节点大小），边 = 同一实验内共现（`weight`=共现记录数）。
- 演示页 `experiment-agent.html` 用 canvas **力导向布局**渲染：取出现频次前 40 的实体、只保留 `weight≥2` 的强连线，避免"毛线团"，节点越大代表该材料/方法越核心。

## 六、演示页（政务蓝白）

`static/experiment-agent.html`，布局：

- **顶栏**：科研实验记录智能体 · SciLog + AdventureX 主题徽标 + 基座/端口标识；
- **Banner**：价值主张（真实数据、可追溯、跨实验图谱、重复预警、效果量化 5 步）；
- **KPI 看板**：接入记录 / 抽取实体 / 跨实验关联 / 潜在重复 / 估算节省时间，随数据实时刷新；
- **左栏**：真实数据接入（拖拽上传 / 多选 / 加载示例 / 清空）+ 记录列表（可删除）；
- **中栏**：基于你的数据问答（带引用、实体标签、建议问题）；
- **右栏**：跨实验知识图谱（canvas 力导向）+ 潜在重复实验预警列表。

打开方式（服务已在 8001）：`http://127.0.0.1:8001/experiment-agent.html`。

## 七、API 一览（端口 8001）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/experiments/upload` | 真实文件上传入库（multipart `file`） |
| GET | `/api/experiments/list` | 已接入记录清单 |
| POST | `/api/experiments/query` | 基于用户真实数据的接地问答 |
| GET | `/api/experiments/graph` | 科研实体共现图 |
| GET | `/api/experiments/metrics` | 平台效果指标 |
| POST | `/api/experiments/seed` | 加载示例实验（真实文件落盘后入库），`{force:false}` |
| DELETE | `/api/experiments/{rec_id}` | 删除某条记录 |

## 八、快速演示脚本（黑客松现场）

1. 打开 `http://127.0.0.1:8001/experiment-agent.html`；
2. 点「**加载示例数据**」→ KPI 看板从 0 跳到 8 条 / 57 实体 / 167 关联 / 3 重复预警；
3. 在问答框输入「**哪种催化剂在 25°C 下产氢速率最高？**」→ 看到带来源的接地回答；
4. 点右侧图谱，讲解「TiO2 / Pt 把 6 个实验连成一张网」；
5. 指重复预警「E1 基准 ↔ E7 重复性验证 56.5% 相似，建议合并」；
6. **杀手锏**：拖入你自己的实验 `.md` / `.csv` / 截图 → 看 KPI 与图谱实时变化，强调"全部基于你的真实数据，不编造"。
