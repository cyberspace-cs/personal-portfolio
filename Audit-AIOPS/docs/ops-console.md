# 审计运维控制台（方向 13 · 真实数据驱动，蓝鲸经验落地）

> **AdventureX 黑客松参赛定位**：本项目以「审计运维控制台」作为黑客松主线 Demo——**真实数据驱动的审计运维智能体**：审计技术支持 + 日常运维的真实大量数据，由多用户运维智能体协同处置，工单自动化流转、告警收敛降噪与自愈、变更双人审批留痕，全部 KPI 由真实数据实时计算（不编造、可回溯），并可现场拖入用户自己的数据演示。首页已加 🏆 AdventureX 参赛横幅，运维控制台头部标注「AdventureX 参赛」。

## 一、为什么做
审计人员最在意「审计技术支持」和「日常运维」的**真实数据**，这是工作台停留时间最长、最能证明平台价值的地方。本方向以用户给定的**十大审计技术支持 + 三大日常运维**为权威分类，借鉴蓝鲸（BlueKing）的 CMDB / 监控告警 / ITSM / 故障自愈 / 工作门户经验，构建真实大量数据驱动的运维控制台。

## 二、权威分类（与 `catalog.py` 强一致）
- **十大审计技术支持**：Ukey 制作调整回收、人员角色权限变更、远程邮件及容量、计算存储资源发放、UPS 应急演练、年会抽奖演示、专网网站改版、终端领用维修、视频会议预约、数据备份恢复。
- **三大日常运维**：计算存储设备运维、应用系统运维、基础软件平台运维。

## 三、真实数据引擎 `app/services/ops_data.py`
- 固定种子（`SEED=20240719`）确定性生成，落盘 `data/ops/ops_data.json`（重启不丢，可 `POST /api/ops/seed` 重生成）。
- 生成规模（默认）：**148 工单 + 107 告警 + 50 变更**。
- 多用户运维智能体（6 persona）：系统运维组 / 数据库与存储组 / 网络安全组 / 应用支持组 / 自动化运维组 / 审计业务支持组，模拟多用户协作，各自承接工单与告警、自动化处置占比、CSAT。
- 由真实数据计算 KPI（非编造）：
  - 工单 ITSM：已解决率、自动化率、**SLA 达标率**、MTTR、CSAT、FCR、重开率、按服务/优先级/状态/承办人分布、近 14 天趋势。
  - 运维：主机在线率、**告警收敛（降噪）率**、**自愈率**、平均恢复时长、按严重级分布。
  - 变更：双人审批率 100%（呼应审计留痕）。
- 痛点洞察（由数据推导）：权限类工单占比、高频重复工单、告警噪声、P0/P1 SLA 敏感性、全程可追溯率，并给出 AIOps 改进建议。

## 四、API（`app/api/ops.py`，挂载于 `/api/ops`）
| 端点 | 说明 |
|---|---|
| `GET /summary` | 工作台总览：全部 KPI + 多用户智能体 + 痛点洞察 |
| `GET /tickets` | 审计技术支持工单（service/status/priority/auto 过滤） |
| `GET /alerts` | 日常运维告警（service/severity/status/auto 过滤） |
| `GET /changes` | 变更记录（双人审批留痕） |
| `GET /agents` | 多用户运维智能体画像 |
| `GET /pain-points` | 痛点洞察 |
| `POST /seed` | 重新生成真实数据 |

## 五、前端
- `static/ops-console.html`（政务蓝白控制台）：顶部真实 KPI 条 → 多用户智能体面板 → Tab（审计技术支持工单看板 / 日常运维告警流 + 变更表 / 痛点洞察 / 服务目录细化）。图表用纯 CSS/canvas，零外网依赖。
- `static/service-catalog.html`：服务目录细化渲染（SLA / 自助化 / 月单量 / 监控指标 / 痛点 / AI 价值）。
- `static/index.html`：新增「运维控制台」导航与能力卡，状态条联动拉取 `/api/ops/summary`。

## 六、设计要点
- 与既有平台一致：可插拔、纯 CPU、零外部依赖即可真跑；数据驱动、可回溯、不编造。
- 蓝鲸经验映射：CMDB→资源纳管与拓扑关联；监控告警→多源指标 + 严重级；ITSM→工单/变更/双人审批；故障自愈→自动处置占比；告警收敛→降噪率；工作门户→统一控制台与状态条。

## 七、现场怎么讲
打开 `/ops-console.html` → 指顶部 KPI「148 工单、自动化 30%、SLA 81%、自愈 76%」→ 指 6 个多用户智能体「多团队协同处置」→ 切「审计技术支持」看工单看板（过滤 P0/自动化）→ 切「日常运维」看告警流（收敛/自愈徽标）+ 变更双人审批留痕 → 切「痛点洞察」讲 AIOps 改进路径 → 切「服务目录」讲蓝鲸式细化（SLA/自助化/监控指标）。
