## 核心项目：Audit-AIOPS · 审计智能一体化运维平台助手（产品负责人 / 产品设计）
**角色**：产品定义 + 需求设计 + 技术对齐 + Demo 演示 ｜ **周期**：【X 个月】 ｜ **形态**：Web 原型 + 可演示后端

**背景与痛点（从 0 到 1 的切入点）**：
审计运维诉求高度碎片化（借终端、开视频会、联网、Ukey、备份……），且一句话常含多件事；
传统工单靠人手动拆、分别找责任人，易"只办一半、中途补单"；知识散、答易错且不可溯源；
高频重复问题反复调大模型成本高，涉密内网要求私有化。

**我的产品工作**：
1. **用户与场景梳理**：归纳一线人员高频诉求与责任人链路，抽象出**服务目录**作为能力边界与产品骨架。
2. **核心链路设计（Agent 编排）**：定义"一句话诉求 → 意图识别 → 自动拆单 → 按事项路由责任人/时限 →
   进度卡片可视化"的主链路，把"动作自动化"作为产品第一价值，而非"能聊天"。
3. **可溯源合规设计**：要求知识问答**强制标注来源**、敏感操作（Ukey 回收/权限调整）**双人审批**，
   把审计合规约束产品化，形成差异化。
4. **成本与私有化策略（有实测数据支撑）**：推动"高频结果缓存复用 + 小模型蒸馏/量化私有化"的产品技术路线，
   把"单轮推理成本"和"私有化可部署"作为关键卖点。与技术侧共同验证：把在线大模型承担的高频意图路由，
   下沉到**蒸馏+INT8 量化+剪枝的小模型**（体积压 63×、CPU 提速 10.8×、98% 稀疏仍无损、精度保持 100%），
   意味着**路由环节可在审计内网 CPU 上毫秒级完成、几乎零边际成本**；生成环节再叠加**投机解码（无损加速 2.14×）**，
   大模型只保留给真正需要生成的环节——直接支撑"降本 + 合规私有化"两大 B 端采购决策点。
   - **检索侧增强（图 RAG）**：推动把"审计实体关系"建图，让问答能召回关系相关但词面未现的知识，提升可溯源覆盖率与回答完整度（已实测 6/6 查询多召回关联文档）。
   - **多模态 RAG 推动（RAG-Anything 思路）**：把文档里的表格（资产台账/权限变更表）与截图（Ukey 制作界面/留痕界面）也纳入统一检索，让"一张表、一张图"也能被问答召回，覆盖纯文本 RAG 漏掉的结构化/视觉信号（已落地演示，端点 `/api/knowledge/multimodal`）。
   - **Prompt 前缀缓存 + 技能中心推动（呼应黄超成本控制与 skill 进化）**：推动"稳定系统前缀复用 prefill KV"的产品化（长系统提示不必每轮重算），并推动把 Agent 能力沉淀为可演进的技能注册表——新增能力零改动编排，审批类技能强制双人审批，使平台"越用越聪明、越用越安全"（已落地：`/api/opt/prompt-cache-report` 实测命中率 99.75%、TTFT↓87.7%、月省 ¥1,496 prefill；`/api/skills` 8 技能清单 + `/agent-demo.html` 技能中心面板）。

   快速对齐业务方，避免长文档空转；定义埋点与上线后指标。
