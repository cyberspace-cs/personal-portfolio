# Smart Service Desk · 智能客服机器人

企业级智能客服系统。前后端分离，蓝白科技感统一风格，无需 API Key。

## 功能
- **意图路由**：物流查询 / 退款退货 / 订单问题 / 投诉建议 / 产品咨询 / 转人工，六类意图自动识别与分流。
- **FAQ 语义匹配**：TF-IDF 余弦相似度匹配知识库，命中即秒级应答。
- **置信度门控**：相关度低于阈值或命中投诉/转人工意图时，自动升级到人工并建议创建工单。
- **工单系统**：一键创建工单跟进，含分类、状态、时间与联系方式。
- **满意度与坐席指标**：实时统计总会话、自助解决率、转人工数、工单数、满意度评分。

## 技术栈
- 后端：Python + FastAPI，意图规则引擎 + TF-IDF FAQ 匹配 + 工单/指标管理。
- 前端：原生 HTML / CSS / JS，聊天 UI + 快捷动作 + 星级评价 + 工单看板；后端离线时降级为浏览器端同构引擎。

## 运行
```bash
cd backend && pip install -r requirements.txt && uvicorn main:app --reload --port 8005
cd ../frontend && python -m http.server 5505   # 打开 http://localhost:5505
```
首次进入自动灌入示例 FAQ，直接提问即可（如「如何申请退款？」「转人工」）。
