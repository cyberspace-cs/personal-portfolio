Core Features

核心功能，一站式解决备考痛点

从题库聚合到智能复盘，覆盖备考全流程的每一个关键环节

多源题库聚合

打通考研、考公、大厂等 12+ 平台题库，一个入口统一刷题，消除切换成本与数据孤岛。

跨平台错题本

自动归集各平台错题，标注知识点与错因，支持智能复盘与针对性重做，不再遗漏薄弱环节。

智能学习路径

基于刷题数据分析知识掌握度，自动生成个性化复习计划与每日推荐，把有限时间用在刀刃上。

进度可视化追踪

刷题量、正确率、知识点掌握度全维度量化，趋势图 + 雷达图直观呈现，备考进度尽在掌握。

模拟考场

按真实考试结构组卷，限时答题 + 全真模拟，提前适应考场节奏，考前冲刺更有底。

多身份适配

考研党、考公党、校招社招求职者，一套系统统筹多类考试复习计划，互不干扰。

关于专属刷题教练

从想法到产品，一路走来的创作历程

📜 创作历程

2026年 4月
💡 想法诞生
在备考过程中发现考研、考公、大厂面试的题库分散在不同平台，反复切换效率极低。萌生了"能不能有一个平台统一管理所有刷题数据"的想法，开始绘制产品草图。
2026年 5月
🛠️ 初赛 Demo
参加 TRAE AI 创造力大赛初赛，完成了第一版原型——包含 6 道题的基础刷题功能、静态数据中心和简单的推荐页面。验证了"多源聚合"这一核心概念。
2026年 6月
📊 数据层重构
引入 localStorage 持久化机制，让刷题记录、错题本、打卡数据真正"活"了起来。智能推荐引擎从静态 mock 数据升级为基于真实错题数据的动态分析。
2026年 7月
🚀 复赛成品
全面升级题库至 21+ 题，新增模拟考场模式（限时答题+自动交卷+成绩单），打造完整的数据中心与智能推荐闭环。加入创作历程展示，让产品更具温度。

✨ 产品亮点

多源聚合引擎

打通考研帮、粉笔行测、LeetCode、牛客网、中公题库等主流平台，统一入口刷题，消灭数据孤岛。

智能推荐算法

基于错题记录分析薄弱知识点，按错误频次和掌握度动态排序，优先推荐最需要强化的题目。

数据可视化

趋势图、雷达图、饼图多维度呈现学习数据，知识点掌握度一目了然，备考进度心中有数。

跨平台错题本

自动归集各平台错题，按知识点+平台归类，记录错误次数与时间，支持智能复盘与针对性重做。

🛠️ 技术栈

HTML5 CSS3 JavaScript (ES6+) Chart.js localStorage 响应式设计 CSS Grid CSS Animations SVG
