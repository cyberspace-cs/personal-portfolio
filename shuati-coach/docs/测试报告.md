## 4. 前端测试

| 用例 | 方法 | 结果 |
|---|---|---|
| JS 语法 | node `vm.Script` 校验 3 个内联脚本块 | 全部 OK（FOUC 381B / 主脚本 59KB / 主题+计划 4.3KB） |
