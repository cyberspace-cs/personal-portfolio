运行方式

本地一键启动 · 无需任何 Key 即可演示
# 1) 启动后端（默认端口，规则降级模式可直接运行）
cd backend && pip install -r requirements.txt
python -m uvicorn app.main:app --port 8011 --reload

# 2) 可选：配置真实模型
set OPENAI_API_KEY=sk-xxx
set OPENAI_BASE_URL=https://your-endpoint/v1

# 3) 启动前端
npm install && npm run dev   # → http://localhost:5173

无 Key 时所有项目以规则降级模式完整演示；配置 Key 后自动升级为真实大模型生成。交互式后端接口位于 http://localhost:8011。
