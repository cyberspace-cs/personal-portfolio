AI 项目 Demo 画廊

大模型 / Agent 全栈项目 · 统一 FastAPI 后端驱动（内置 Prompt / RAG / Skill / MCP / Context Harness Loop 内核）

运行方式

# 1) 启动后端（默认 8011 端口，无需任何 API Key 即可运行）
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8011 --reload
# 可选：配置真实模型
set OPENAI_API_KEY=sk-xxx
set OPENAI_BASE_URL=https://your-endpoint/v1

# 2) 启动前端（另一个终端）
npm install && npm run dev
# 打开 http://localhost:5173 → Projects 区点击「演示」

无 Key 时所有项目以规则降级模式完整演示；配置 Key 后自动升级为真实大模型生成。交互式 Demo 接口位于 http://localhost:8011。
