前面的世界模型还在实验室，但有一类 Agent 已经能长期跑在你的电脑上。它最迷人的能力是：自己从经验里学，而且不跑偏。

AutoTalon 本地优先、可长期运行，核心是一个"带护栏的操作型运行时"。每次调 shell、写文件、联网都要过沙箱和审批，全程留审计日志和回滚快照。所谓"自动进化"，是一个经验→技能的人工审核闭环：执行内核发出生命周期事件，经验采集器把成功或失败记成候选经验，人工审核采纳后才进上下文。

举一段它怎么工作的具体画面。你让它"每周一把上周的会议纪要整理成待办"。第一次它手忙脚乱：先找错文件夹，再用错了命令，折腾半天。执行内核把这次的每一步（在哪个目录、调了什么、成功还是报错）记成 trace。经验采集器从中提炼出"整理纪要的标准流程"作为候选技能，标成 candidate。你审查发现流程没问题，点"采纳"，它变成 accepted 的 skill。第三次再接到同样任务，它直接调这个 skill，三分钟搞定——这就是"经验沉淀成能力"。

关键护栏在于——只有当某个模式被反复验证（比如至少成功 3 次、成功率≥80%、稳定性≥0.6），PromotionAdvisor 才自动起草一个 skill 草稿，等你签字。skill 不是改源码的补丁，而是可复用的操作说明书。这防止一次偶然成功被当成真理，保证行为稳定可信任。我特别欣赏这点：很多"会自我进化"的 Agent Demo 看着吓人，但其实谁也没法审计它到底学了什么；AutoTalon 把每一步都摊在桌面上，你随时能回滚。为什么用 TypeScript+Node 而非 Python？因为它依赖 npm 的实时运行时和异步 I/O，方便本地长期驻留，对纯前端背景的人接入门槛也更低。

下面是五阶段自学路线图。别想一次吃成胖子，沿路径分阶段建能力栈。每阶段我都标了"什么时候算过关"和"该进阶的信号"。

阶段一·计算机基础（约 2 月）：网络/OS/算法。验收——能讲清输入 URL 到页面渲染的全过程。进阶信号：你能对着开发者工具讲出一次请求的每一步。跳过这阶段的后果：后面学推理优化、学部署，永远隔着一层"黑盒感"。

阶段二·全栈开发与部署（约 3 月）：前端框架+后端+数据库+Git，用 Supabase 降门槛。验收——GitHub 托管一个完整 Web 应用并部署到生产环境。进阶信号：你接到需求不再先搜"怎么做"，而是先画数据流。这是把"想法"变成"别人能用的东西"的门槛。

阶段三·AI 模型原理与实战（约 4 月）：Transformer、推理优化（Prefill/Decode、KV Cache、FlashAttention）、用 vLLM 跑通开源模型、LoRA 微调。验收——能用 vLLM 跑模型并用 LoRA 在自有数据上微调。进阶信号：你能解释为什么你的服务"慢三倍"。这是整套路线图里最硬、也最值得啃的一段。

阶段四·前沿方向探索（终身学习）：读顶会论文、跟开源项目，保持对具身/世界模型/多模态的感知。不是为了成专家，是技术迭代时你知道从哪切入。进阶信号：看到一个新技术，你能判断它解决了哪一类老问题。

阶段五·Agent 工程（从看懂到能做）：掌握规划、工具调用、记忆，用 LangChain/AutoTalon 构建可执行系统。验收——能构建一个稳定运行的自主 Agent。进阶信号：你不再写死每一步，而是给 Agent 目标和护栏，让它自己跑。

一个可落地的起点：这周就做一件事——花几天看懂"浏览器请求全程"，动手用 Node 写个能查数据库的极简接口，再用 Supabase 部署出去。别等"学完再动手"，地图是走出来的。

路线图之外，说几个能省钱省时间的习惯。别纠结学哪门语言——路线图里 Python、TypeScript、Node 都是工具，真正复用的是"系统怎么运转"的直觉，语言几天就能切换。社区方面，Datawhale 的 Easy-Vibe、各类开源教程仍是很好的脚手架，但请把它当地图而不是终点，遇到不懂的顺着链路自己查，别停在"照着敲能跑"。

还有，别被"速成"收割。凡是号称"七天成为 AI 工程师"的，基本在卖焦虑。这份十二篇路线图算下来要一年左右，其中第三阶段（模型原理）最磨人但也最值钱——它决定了你能不能从"调 API 的人"变成"能判断 API 靠不靠谱的人"。慢就是快。

走完这十二站，不妨回头看一眼整张地图长啥样：第 1 站建立"为什么需要地图"的意识；第 2-6 站从一次浏览器请求串起 URL、DNS、TCP、HTTP、渲染、全栈，让你看懂数据从鼠标到屏幕的全程；第 7-10 站钻进 LLM 推理，把 Prefill/Decode、KV Cache、GQA、FlashAttention、PagedAttention 一个个拆开，弄懂"为什么同样的模型有的快有的卡"；第 11 站跳出屏幕看具身智能和世界模型；第 12 站收束到一个能自我进化的 Agent 和你的学习路线。你会发现，前六站是地基，后六站是上层建筑——地基不牢，上层建筑学了也飘。

最后一句实在话：地图再好，也得你亲自走。我见过太多人把教程收藏了就等于学会了，三个月后啥也没留下。挑最小的一个动作今天就开始——比如现在就打开终端，敲 `dig +trace 一个你常访问的域名`，亲眼看看 DNS 怎么一层层问到答案。那一下"原来如此"的顿悟，比收藏一百篇教程都管用。

地图展开的方式有很多种，命令行只是最朴素的那种。你也可以在纸上画、用思维导图、或者写进自己的笔记里——形式不重要，重要的是它真在你脑子里长出来，而不只是躺在收藏夹里吃灰。

如果你读到这里，说明你不是只想"用用 AI"，而是想真正搞懂它。这十二篇只是张地图，真正的地形得你自己走。下一篇没有下一篇了——合上屏幕，去搭你的第一个能查数据库的接口，或者跑通你的第一个开源模型。地图的价值，在出发。

成为 AI 工程师不是终点，是你拥有了一张不断更新的地图——知道去哪查、怎么补。今天就从阶段一第一节课开始。剩下的路，会随你迈出的每一步逐渐清晰。
