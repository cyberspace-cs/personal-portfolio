## 一、行业基准：347 份 Agent JD 的统计结论（适配总基线）

来源：拆了 347 份 Agent 岗位 JD（26 万字），智联招聘 2026-06 采集。这是「市场筛人规则」，决定简历的底线关键词。

### 1.1 岗位分布
| 岗位类型 | 占比 |
|---|---|
| 通用 Agent 开发工程师 | 65.4% |
| 大模型 / LLM 方向 | 8.4% |
| 产品经理方向 | 6.3% |
| 算法方向 | 4.6% |
| 后端 / 服务端 | 3.7% |
| 全栈 | 2.9% |
| 数据 / 前端 / 测试 / 运营 | 8.6% |

> 结论：**65% 的岗位是「通用 Agent 开发工程师」，不要求死磕算法/后端**。简历主线应是「Agent 应用落地」，而非纯科研。

### 1.2 技能词频（决定 ATS 命中）
- **必须会（>50%，不写被筛掉一半）**：Agent 架构设计 72.9% · Python 57.9% · LLM 55.9% · RAG 47.6%
- **核心竞争区（30–50%，决定进面试）**：LangChain 38.3%（远超 LlamaIndex 12.7%）· API/接口开发 37.2% · Prompt Engineering 36.9% · Java 30.5%
- **加分项（10–30%，拉薪资上限）**：模型微调 20.2% · Go 19.9% · Docker 18.4% · **Dify 15.3%** · 高并发/分布式 15.3% · **AutoGen 15.0%** · **MCP 14.4%（2026 新标配）** · Function Call 13.5% · LlamaIndex 12.7% · FastAPI 11.8% · MySQL/Redis
- **高频业务词**：设计 73.2% · 优化 73.2% · 开发 72% · Agent 72.9% · **「落地」65.7%（超过 Python）** · 协作 61.4%
- **软性**：独立工作能力 45% · 项目经验 24.8% · **开源贡献 20.5%** · 学习能力 18.2%

### 1.3 可直接复用的 ATS 关键词块
```
AI Agent | LangChain | RAG | Prompt Engineering | Multi-Agent | AutoGen | MCP
Function Calling | Python | FastAPI | Go | Java | LLM | Fine-tuning | LoRA
Docker | Kubernetes | Redis | MySQL | Vector Database | Milvus | Elasticsearch
```

### 1.4 适配铁律（写进每条经历）
1. **每行技能配量化落地案例**：❌「了解大模型」→ ✅「基于混元搭建 Agent 对话系统，评测 hit_rate=0.667/citation_rate=1.0」
2. **强制嵌入「落地」证明**：技术栈 + 规模 + 效果指标 + 上线状态。
3. **突出协作与架构职责**：61.4% 强调跨团队，73.2% 要求系统设计。
4. **补 2026 新标配词**：MCP / Dify / AutoGen 展示前沿敏感度。
5. **经验定位**：1–5 年最友好，本科为主力；应届用开源贡献/落地项目弥补。

- **代表岗位**：混元大模型应用算法工程师 / 混元 Agent 开发工程师

#### DeepSeek（应用开发 / 全栈 / AI 产品）

- **能力画像**：**既懂算法又懂系统**；极致性能优化（榨干硬件/RDMA/InfiniBand/GPU 集群/算子编译器）；PyTorch/C++/Python/分布式；开源贡献优先；自驱 0→1。
- **适配钩子（工程）**：零依赖规则降级 + 可观测 + 编译全过 + 推理极致优化 + 成本自负盈亏 + 开源复用。

## 三、简历打磨的 6 条具体改动（应用到基础简历）

1. **ATS 关键词前置**：技术栈第一行放 LangChain/LangGraph、RAG、Multi-Agent、MCP、Function Calling、FastAPI（对齐 347 统计）。
2. **每条经历补「落地四件套」**：技术 + 规模 + 指标 + 上线。例：把「实现 RAG」改为「RAG（TF-IDF+2-gram+RRF）落地，citation_rate=1.0、hallucination_rate=0.0，已上线」。
3. **突出开源/复用**：把「两个 Trending 项目复用同一 core」提到 技术总结 首句，命中「开源贡献 20.5%」。
4. **补 2026 新标配词**：MCP（Phase H 已落地）、Dify（低代码生态叙事）、AutoGen（多 Agent 同构）显式写入。
5. **量化统一口径**：hit_rate / citation_rate / reject_rate / hallucination_rate / speedup≈8x / kv_cache_hit_rate≈0.8 作为固定数字资产，每版复用。
6. **PM 方向补「低代码/生态/可解释」**：对齐京东/百度 AppBuilder 类岗位；工程方向补「系统/分布式/开源」对齐 DeepSeek/字节。
