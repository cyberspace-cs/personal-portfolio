面试官好，我是【姓名】。我最有代表性的项目，是把一个复赛刷题工具升级成了**生产级的备考 Agent「专属刷题教练」**。

它不是套壳聊天框，而是用 **LangGraph 同构编排**把诊断、讲题、变式、规划、反思串成多智能体；用 **RAG 引用溯源 + 低相关拒答**做到不讲废话、不编答案；还把 **AIOps 异常检测**迁移到学习场景，主动预警正确率骤降和连续断签；并自建**评测闭环**量化命中率、引用率和幻觉率。

更重要的是，它**推理成本敏感**：五段式上下文预算本质是 context 压缩，稳定前缀能 KV cache 复用，能查库就不让模型生成，反思节点是确定性的、不额外解码。我也规划了用 **vLLM 私有化 + AWQ 量化 + 蒸馏小模型**做边缘答疑。

我从部委事业单位跳出来，在 48 小时黑客松从 0 做出这个产品，既懂定义也懂落地。希望进贵团队，把 Agent 编排和推理优化继续做深。谢谢！
