# 简历分厂适配系统 · 提升效果 / 用户场景 / Trae 复赛应用

> 一句话价值：**把一份简历，变成「对每一家厂、每一个岗位都说对方语言」的 22 份精准简历**，且全程数据驱动、可一键重生成。
> 配套交付：`招聘调研与适配策略.md` + `简历生成器/`（data.js + companies.js + generate.js → output/*.docx）。

---

## 一、提升效果（相对「一份通投简历」）

### 1.1 ATS 命中率显著提升
- **问题**：通用简历常因缺关键词被机筛淘汰。347 份真实 Agent JD 统计显示，Agent 架构设计(72.9%)、Python(57.9%)、LLM(55.9%)、RAG(47.6%) 是硬门槛，MCP(14.4%)/Dify(15.3%)/AutoGen(15%) 是 2026 新标配。
- **做法**：技术栈首行强制埋入 LangGraph/LangChain/RAG/Multi-Agent/MCP/Function Calling/FastAPI；每份简历尾部附「岗位匹配关键词」红字块，与 JD 词频对齐。
- **预期**：机筛通过率从「看运气」变为「覆盖 90%+ 高频关键词」。

### 1.2 从「我有什么」到「你要什么」（重排重帧）
- 同一段项目经历（刷题教练 Agent 升级），按厂调整**呈现顺序与强调点**：
  - 字节 Seed → 先抛「多 Agent 编排 + 评测闭环 + 搜索 RAG + 推理 Benchmark」；
  - 腾讯混元 → 先抛「RAG 防幻觉 + 记忆多轮 + 混元优先 + 反思强化」；
  - Kimi → 先抛「推理优化(vLLM) + 结构化输出 + 开源复用」；
  - 宇树/智元 → 先抛「机器人任务规划 + 端侧部署 + 低延迟」。
- **预期**：面试官在 8 秒扫读内看到「这正是我们招的人」，进入面试概率提升。

### 1.3 量化资产统一、可信
- 固定数字资产：citation_rate=1.0 · hallucination_rate=0.0 · hit_rate=0.667 · speedup≈8x · kv_cache_hit_rate≈0.8 · 两开源项目 GitHub Trending。
- 每条技术都配「规模+指标+上线」落地四件套，命中 JD 高频业务词「落地(65.7%)」。

### 1.4 效率：从「改 3 天」到「改 1 行配置」
- 新增一家厂只需在 `companies.js` 加一条配置（求职意向 + 技术栈优先级 + Phase 重排 + 关键词），`node generate.js` 秒出 docx。
- 基础内容只维护一份（`data.js`），杜绝多份简历内容漂移。

### 1.5 覆盖完整：5 大厂 + 15 典型中小厂
- 大厂：字节 Seed / 腾讯混元 / 智谱 / Kimi / DeepSeek（含 DeepSeek AI 产品）。
- 中小厂（≤20）：京东 / 快手 / 阶跃星辰 / 宇树 / 智元 / 银河通用 / 阿里通义 / 百度 / MiniMax / 百川 / 商汤 / 美团 / 星海图 / 星动纪元 / 灵初智能（具身智能为主）。

## 二、实际用户场景

### 场景 A：应届/初级求职者海投大模型岗
- **痛点**：不懂各厂技术栈差异，一份简历通投，石沉大海。
- **用法**：在 `companies.js` 勾选目标厂 → 运行生成器 → 拿到 22 份「对厂说话」的 docx → 按投递顺序逐一导出。
- **收益**：每份简历都「像为该厂专门写的」，且复用同一项目资产，零额外写作成本。

### 场景 B：用「刷题教练」作面试亮点项目
- 用户主导的「专属刷题教练」已从复赛工具升级为定制化备考 Agent（LangGraph + 混元/通义 + MCP + 分层记忆 + RAG 溯源 + 反思防环 + 评测闭环）。
- 简历中该项目的 8 个 Phase 可**按面试官背景即时重帧**：对算法面试官讲评测与推理优化，对应用面试官讲落地与工程，对产品面试官讲需求与指标。

### 场景 C：跨方向求职（工程 ↔ 产品）
- 同一项目资产，工程方向简历强调「框架/优化/评测」，产品方向简历强调「痛点/生态/指标」。
- 已生成：工程版（17 家）+ 产品版（京东 / DeepSeek AI 产品 / 快手 Agent 运营）。

### 场景 D：招聘季快速迭代
- JD 变动或拿到面试反馈 → 改 `data.js` 一处 → 全量重生成 → 所有分厂版本同步更新，不留旧版本。

## 三、Trae 创造力大赛复赛应用

本系统本身就是「AI 辅助创作 / vibe-coding」的范例，可直接作为复赛素材：

1. **作品即方法论**：用「数据驱动 + 模板重排」解决「千人千面简历」真实痛点，体现工程化思维与产品 Sense。
2. **可复用组件**：`data.js`（内容资产）+ `companies.js`（策略资产）+ `generate.js`（渲染）三层解耦，评委可一眼看懂架构。
3. **亮点叙事**：
   - 「基于 347 份真实 JD 统计做 ATS 关键词对齐」——用数据说话；
   - 「一份内容 → 22 份精准简历」——规模化个性；
   - 「刷题教练项目」本身就是复赛晋级作品，形成「作品→简历→作品」闭环。
4. **可直接演示**：现场 `node generate.js` 即出 22 份 docx，演示「一次维护、全厂适配」。
