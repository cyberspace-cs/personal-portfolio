# 数据库设计

竞赛雷达使用 **SQLite**（原生 `sqlite3`，无 ORM 依赖），数据文件位于 `server/data/competition.db`。
所有表均在 `server/database.py` 的 `init_db()` 中幂等创建，并启用外键约束与 WAL 模式。

---

## 表关系

```
users ──< auth_tokens          (1 个用户可有多条有效 token)
users ──< favorites >─── competitions
categories ──< competitions
competitions ──< competition_tags >─── tags
```

---

## 表结构

### 1. categories（竞赛分类）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| name | TEXT | 分类名称，如「黑客松」「数据竞赛 / Kaggle」 |
| slug | TEXT UNIQUE | URL 友好标识，用于筛选（`?category=hackathon`） |
| icon | TEXT | 展示图标（emoji 或字符） |
| description | TEXT | 分类简介 |
| sort_order | INTEGER | 展示排序 |

### 2. competitions（竞赛主表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| title | TEXT | 竞赛名称 |
| slug | TEXT UNIQUE | URL 友好标识 |
| summary | TEXT | 一句话简介（卡片展示） |
| description | TEXT | 详细介绍（详情页，多段以 `\n` 分隔） |
| category_id | INTEGER FK→categories | 所属分类 |
| organizer | TEXT | 主办方 |
| location | TEXT | 地点（城市或「线上」） |
| mode | TEXT | 形式：`online` / `offline` / `hybrid` |
| prize | TEXT | 奖金文案，如「¥ 100,000」 |
| prize_amount | INTEGER | 奖金数额（数字，用于排序） |
| status | TEXT | 状态：`upcoming` / `ongoing` / `ended` |
| start_date | TEXT | 开始日期（YYYY-MM-DD） |
| end_date | TEXT | 结束日期 |
| reg_deadline | TEXT | 报名截止日期 |
| tags | TEXT | 标签，以 **JSON 数组** 存储，如 `["AI","黑客松"]` |
| cover | TEXT | 封面图 URL（为空时前端按标题生成渐变） |
| source_url | TEXT | 官网 / 报名链接 |
| featured | INTEGER | 是否精选（0/1） |
| views | INTEGER | 浏览量（详情接口自动 +1） |
| created_at / updated_at | TIMESTAMP | 时间戳 |

> 索引：`category_id`、`status`、`featured` 上建有索引以加速筛选与排序。

### 3. tags（标签字典）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| name | TEXT UNIQUE | 标签名 |

### 4. competition_tags（竞赛-标签多对多）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| competition_id | INTEGER FK→competitions | 竞赛 ID（级联删除） |
| tag_id | INTEGER FK→tags | 标签 ID（级联删除） |

> 注：当前列表筛选 `?tag=` 通过 `competitions.tags` 的 JSON 模糊匹配实现；`tags` / `competition_tags` 表保留用于未来结构化标签管理。

### 5. users（用户）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| username | TEXT UNIQUE | 用户名（3–32 字符） |
| email | TEXT | 邮箱（可选） |
| password_hash | TEXT | PBKDF2-SHA256 哈希（`salt$hash`） |
| avatar | TEXT | 头像 URL |
| role | TEXT | 角色：`user` / `admin` |
| created_at | TIMESTAMP | 注册时间 |

### 6. auth_tokens（登录令牌）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| token | TEXT PK | 随机 URL-safe Token（32 字节） |
| user_id | INTEGER FK→users | 所属用户（级联删除） |
| expires_at | TIMESTAMP | 过期时间（默认 30 天） |
| created_at | TIMESTAMP | 签发时间 |

### 7. favorites（收藏）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| user_id | INTEGER FK→users | 用户（级联删除） |
| competition_id | INTEGER FK→competitions | 竞赛（级联删除） |
| created_at | TIMESTAMP | 收藏时间 |

> 唯一约束 `(user_id, competition_id)`，避免重复收藏。

---

## 初始化与示例数据

- `init_db()`：创建全部表（可重复执行）。
- `seed.py`：写入 8 个分类与 24 条示例竞赛（幂等：`slug` 已存在则跳过）。应用启动时若竞赛表为空会自动调用。
- 重置数据：删除 `server/data/competition.db*` 后重新运行 `python seed.py`。
