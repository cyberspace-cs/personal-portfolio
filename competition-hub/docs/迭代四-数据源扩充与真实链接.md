# 迭代四 · 数据源扩充 + 真实赛事链接

> 目标：用户要求「扩充数据源，而且这些也得有竞赛链接」——即（1）接入更多赛事来源；（2）每条赛事都必须带可点击的真实竞赛链接（而非平台首页）。

## 一、关键发现

- 上一版 `collector_sources.json` 的 16 条记录多数 `source_url` 指向**平台首页**
  （如 `https://www.kaggle.com/competitions`、`https://tianchi.aliyun.com`），并非具体赛事，
  不满足「竞赛链接」要求。
- 通过 WebFetch 实测确认：Kaggle / DataFountain 的列表页为**前端渲染**，
  `curl` 原始 HTML 中**抓不到**具体竞赛链接（bot UA 拿到的是 JS 壳）。因此无法用
  `urllib` 适配器直接抓取，但 WebFetch 能拿到**真实、当前的**竞赛 URL。
- 华为云 competitions 路径返回 404；和鲸 / 极客镇未暴露具体赛事 URL。

## 二、方案

### 1. 扩充 `collector_sources.json` 为真实链接数据集（62 条 / 10 类来源）
经实测核实的链接来源：

| 来源 | 条数 | 链接形态（已抽样 HTTP 200） |
| --- | --- | --- |
| Kaggle | 25 | `https://www.kaggle.com/competitions/<slug>` |
| DataFountain | 15 | `https://www.datafountain.cn/competitions/<id>` |
| 百度 AI Studio | 10 | `https://aistudio.baidu.com/competition/detail/<id>` |
| 腾讯云开发者社区 | 6 | `https://cloud.tencent.com/developer/competition/introduction/<id>` |
| 阿里云天池 | 1 | `https://tianchi.aliyun.com/competition/entrance/<id>` |
| 研究生数模 / 工业设计 / 强网杯 / 天府杯 / 京东 | 各 1 | 官方赛事站点 |

> 用一次性生成脚本（`_gen_sources.py`）产出 JSON 后删除，避免手写 62 条 JSON 出错；
> 所有条目 `source_url` 均以 `http` 开头（已断言）。

### 2. UI 真实链接直达
- `CompetitionCard.tsx`：
  - 「聚合自 {来源}」徽标改为可点击链接（新标签页打开 `source_url`，`preventDefault+stopPropagation` 避免误触详情跳转）；
  - 卡片底部新增「↗ 官网」链接，直达原赛事页面。
- 详情页原本已有「前往官网 / 报名」按钮（`source_url`），保持不变。

### 3. 数据刷新
- 清空旧 18 条（含首页链接的占位数据），重新聚合：
  `DELETE FROM competitions` → `run_collection()` → 62 条 bundle + 2 条 heikesong 实时 = **64 条**，`failed:0`。
