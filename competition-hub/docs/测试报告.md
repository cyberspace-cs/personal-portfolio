## 1. 测试环境与方式

- **框架**：`pytest` + `fastapi.testclient.TestClient`（starlette 内置 httpx 测试客户端）。
- **依赖**：`httpx`、`pytest`（安装于项目 venv `server/.venv`）。
- **数据隔离**：通过环境变量 `DB_DIR` / `DB_NAME` 将测试指向系统临时库的独立 `test.db`，由 `startup` 事件 `init_db()` + `seed_if_empty()` 自动建表并播种示例数据，与开发/生产库完全隔离。
- **限流隔离**：用例级 `autouse` fixture 清空内存限流计数 `_auth_hits`，避免用例间相互干扰。
- **执行命令**：在 `server/` 下运行
  ```bash
  .venv/Scripts/python.exe -m pytest tests/ -q
  ```
