## 2. 问题清单（按严重度）

### 🔴 严重 / 重要（必须修复）

| 编号 | 严重度 | 位置 | 问题 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 重要 | `main.py` CORS 配置 | `allow_origins=["*"]` 同时 `allow_credentials=True` | 既违反 CORS 规范（带凭据不允许通配），又对任何站点开放跨域凭证请求，存在 CSRF/数据泄露面 |
| R2 | 重要 | `main.py` 安全响应头 | 未设置 CSP / X-Content-Type-Options / X-Frame-Options / Referrer-Policy | Token 存 localStorage，缺安全头加剧 XSS 窃取与点击劫持风险 |
| R3 | 重要 | `main.py` 认证限流 | `/api/auth/login`、`/register` 无限流 | 可被暴力破解 / 批量刷号 |

### 🟡 一般（建议修复）

| 编号 | 严重度 | 位置 | 问题 | 风险 |
| --- | --- | --- | --- | --- |
| R4 | 一般 | `models.py` 输入校验 | `title/summary/organizer` 等无最大长度；`tags` 无数量上限；`mode/status` 未限定枚举 | 异常长文本 / 垃圾枚举值写入，影响展示与统计 |
| R5 | 一般 | `main.py` 错误回显 | 异常可能回显内部信息（依赖 FastAPI 默认） | 信息泄露（低） |
| R6 | 一般 | `database.py` | `competitions.tags` 为 JSON 字符串，`?tag=` 用 `LIKE '%\"tag\"%'` 模糊匹配 | 标签名含引号时匹配不准（功能性，非安全） |

### 🟢 建议（优化）

| 编号 | 严重度 | 位置 | 建议 |
| --- | --- | --- | --- |
| R7 | 建议 | 架构 | 生产应引入管理员角色，限制「发布/编辑」权限，避免任意登录用户写竞赛 |
| R8 | 建议 | 前端 | 收藏/提交等写操作可加乐观更新 + 失败回滚的更细粒度提示 |
| R9 | 建议 | 测试 | 补充自动化测试（TestClient）覆盖核心链路与限流/校验边界 |

## 3. 质量与架构评价（亮点）

- ✅ **零 SQL 注入**：所有查询参数化，无字符串拼接。
- ✅ **密码安全**：PBKDF2-SHA256 加盐，绝不存储明文。
- ✅ **关注点分离清晰**：API 客户端、鉴权 Context、UI 组件解耦。
- ✅ **幂等设计**：收藏 `INSERT OR IGNORE`、退出失效 Token。
- ✅ **SPA 深链回退**：生产托管前端且 `/{path}` 回退 index.html，架构合理。
- ✅ **可观测**：启动打印 AI/DB 状态、健康检查端点。

## 5. 复检清单（Fix 阶段回填 · 2026-07-22 复检通过）

- [x] **R1** CORS 收敛为可信源：新增 `_ALLOWED_ORIGINS`，读环境变量 `ALLOWED_ORIGINS`（默认 `http://localhost:5173`），`allow_credentials=True` 仅对可信源生效；methods/headers 收敛为白名单。
- [x] **R2** 安全响应头中间件 `_security_headers`：写入 `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: strict-origin-when-cross-origin`、`Content-Security-Policy`（self 基线 + `frame-ancestors 'none'`）、`Permissions-Policy`。
- [x] **R3** 认证限流 `_check_auth_rate_limit`：按客户端 IP 固定窗口限流（10 次 / 60 秒），超限返回 `429` + `Retry-After`。`register` 与 `login` 已接入。
- [x] **R4** 输入校验（`models.py`）：`title/summary/organizer/location/prize/cover/source_url/slug` 等加 `max_length`；`mode`、`status` 限定 `Literal` 枚举；`tags` 限 10 个且单标签截断 30 字符。
- [x] **复检**：服务启动正常，核心链路（health / 分类 / 列表筛选搜索 / 详情 / 注册登录 / 收藏 / CRUD / 限流 / 校验）端到端自测通过 —— 见《测试报告》。

### 复检证据摘要
- 安全头验证：12/12 通过（`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Content-Security-Policy`、`Permissions-Policy` 均命中；CORS 对可信源正确回显、对不可信源不回显）。
- 限流验证：连续注册触发 `429` 且带 `Retry-After: 60`。
- 输入校验验证：9/9 通过（超长 title / 非法 mode / 非法 status / tags 超量 均被 Pydantic 拒绝，合法与自动清洗用例通过）。

> 备注：R2 的 CSP 为兼容 SPA 构建暂保留 `script-src 'self' 'unsafe-inline'`，列为后续加固项（见 R2-followup）。
